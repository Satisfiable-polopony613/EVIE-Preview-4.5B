## 🛠️ Troubleshooting Common Issues

**Issue: Program won't start after installation.**
- Make sure you downloaded the full installer (not a partial download). Re-download if in doubt.
- Temporarily disable antivirus during installation (some tools block new executables).

**Issue: Search returns no results.**
- Confirm documents are loaded (check the left sidebar shows file names).
- Try a broader term (e.g., "report" instead of "Q3 fiscal report 2024").
- For scanned pages, ensure the scan quality is above 100 DPI.

**Issue: Slow processing for a large folder.**
- Close other heavy programs.
- Reduce number of files per batch (load 500 at a time instead of 5000).
- Enable GPU acceleration in Settings if available.

**Issue: Chinese or special characters look garbled.**
- Install the appropriate language pack (Settings → Language Packs → Install).
- For scanned Chinese docs, ensure the document is upright (rotate if needed).
